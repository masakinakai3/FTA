# FTAエディタ (故障の木解析)

React, TypeScript, Viteで構築された、モダンなWebベースのFTA（故障の木解析）エディタです。このツールを使用すると、洗練されたダークテーマのインターフェースでフォールトツリーを作成、検索、解析することができます。

## 🚀 機能

### コア機能
- **ビジュアル編集**: 無限キャンバスを使用したドラッグ＆ドロップインターフェース。
- **ノードの種類**:
    - **事象 (Events)**: トップ事象、基本事象、中間事象、未展開事象。
    - **ゲート (Gates)**: ANDゲート、ORゲート。
    - **注釈**: ラベルやメモ用のテキストボックス。
- **接続**: 綺麗な直交ルーティングによる接続。左から右へのフロー。
- **永続化**: JSONファイルとしてダイアグラムを保存・読み込み可能。
- **エクスポート**: ツリー全体の高解像度PNG画像をエクスポート。

### UI/UX
- **ダークモード**: デフォルトで没入感のあるダークテーマ。
- **カスタマイズ**: プリセットパレットを使用してノードの色を変更可能。
- **複数選択**:
    - **ボックス選択**: 背景をドラッグして複数のノードを選択。
    - **修飾キー**: Shift/Ctrl + クリックで選択の切り替え。
- **ナビゲーション**:
    - **パン（移動）**: 中クリック、または スペースキー + 左ドラッグ。
    - **ズーム**: マウスホイール。

## 🛠️ 技術スタック

- **フレームワーク**: [React 19](https://react.dev/)
- **ビルドツール**: [Vite](https://vitejs.dev/)
- **言語**: [TypeScript](https://www.typescriptlang.org/)
- **状態管理**: React Hooks (カスタム `useFTATree` フック)
- **スタイリング**: CSS Modules / Native CSS Variables

## 🏁 始め方

### 前提条件
- Node.js (v18以上推奨)
- npm または yarn

### インストール

1.  **リポジトリのクローン**:
    ```bash
    git clone https://github.com/masakinakai3/FTA.git
    cd FTA
    ```

2.  **依存関係のインストール**:
    ```bash
    npm install
    ```

3.  **開発サーバーの起動**:
    ```bash
    npm run dev
    ```

4.  **ブラウザで開く**:
    `http://localhost:5173` にアクセスしてください。

## 📖 ユーザーガイド

### 1. ノードの追加
画面上部の **ツールバー** を使用します。
- **事象**: "Top"(トップ), "Basic"(基本), "Inter"(中間), "Text"(テキスト) をクリック。
- **ゲート**: "AND", "OR" をクリック。
- 新しいノードはビューポートの中央に表示されます。

### 2. レイアウトと移動
- **ノードの移動**: ノードをドラッグして再配置します。
- **自動レイアウト**: ノードを追加すると中央付近に配置されますが、自由に整理できます。標準的なFTAのフローは通常、トップダウンまたは左から右です。**このエディタは左から右（Left-to-Right）のレイアウトに最適化されています。**

### 3. ノードの接続
1.  **開始**: 親/ソースノードをダブルクリックする（オレンジ色に光ります）、または `Shift` を押しながらノードをクリックします。
    - あるいは、ノードの下/右にある小さな青い **出力ポート** をクリックします。
2.  **終了**: ターゲットとなる子ノードをクリックします。
3.  **結果**: 直角の線で接続されます。

### 4. 選択と削除
- **単一選択**: ノードまたはエッジをクリックします。
- **複数選択**: `Shift` または `Ctrl` を押しながらノード/エッジをクリックします。
- **エリア選択**: 何もないキャンバス背景をクリックしてドラッグし、選択ボックスを描画します。
- **削除**: `Delete` または `Backspace` キーを押して、選択されたすべてのノードと接続を削除します。

### 5. プロパティ
ノードを選択すると、右側の **プロパティパネル** に詳細が表示されます。
- **ラベル**: ノードの名前を変更します。
- **説明**: 詳細を追加します。
- **色**: パレットからカスタムカラーを選択します。

### 6. 保存とエクスポート
- **JSON保存 (Save JSON)**: ダイアグラムのデータ（構造、位置）を `.json` ファイルに保存します。
- **JSON読み込み (Load JSON)**: 保存された状態を復元します。
- **画像エクスポート (Export Image)**: 現在のズーム/パンに関係なく、ダイアグラム *全体* をPNGとしてキャプチャします。

## 💾 データモデル

アプリケーションは永続化のためにシンプルなJSON構造を使用しています:

```typescript
interface FTANode {
  id: string;       // UUID
  type: string;     // 'event' | 'gate'
  subType: string;  // 特定のタイプ
  label: string;
  x: number;
  y: number;
  // ...
}

interface FTAEdge {
  id: string;
  sourceId: string;
  targetId: string;
}
```
